بسته انتشار نرم‌افزار اندرویدی «پایش تربیتی» - نسخه ۱۵.۱
=============================================================

این ZIP را برای بارگذاری مستقیم در GitHub Pages یا هر هاست استاتیک آماده کرده‌ایم.

محتویات:
- index.html : صفحه اختصاصی دانلود فارسی و واکنش‌گرا
- Payesh-v15.1.apk : همان فایل APK ارسالی شما، بدون هیچ تغییری
- assets/logo.png : لوگوی واقعی استخراج‌شده از نرم‌افزار
- assets/app-screen.webp : تصویر واقعی صفحه آغازین
- assets/poster.webp : پوستر معرفی
- assets/og-share.jpg : تصویر پیش‌نمایش هنگام اشتراک‌گذاری لینک
- assets/favicon.png : آیکون مرورگر
- .nojekyll : برای انتشار سازگار با GitHub Pages

راه انتشار رایگان با GitHub Pages:
۱. وارد github.com شوید (دسترسی بدون فیلترشکن به شبکه/اپراتور شما بستگی دارد).
۲. یک مخزن Public با نام مثلاً payesh-download بسازید.
۳. فایل ZIP را در گوشی یا رایانه استخراج کنید.
۴. همه فایل‌ها و پوشه assets را در ریشه مخزن بارگذاری کنید (Upload files > Commit changes).
۵. Settings > Pages > Build and deployment > Source: Deploy from a branch.
۶. Branch: main و Folder: /(root) را انتخاب کرده و Save بزنید.
۷. کمی صبر کنید تا سایت فعال شود. آدرس معمولی:
   https://YOUR-USERNAME.github.io/payesh-download/
   عبارت YOUR-USERNAME را با شناسه واقعی GitHub خود جایگزین کنید.
۸. لینک واقعی را در کانال‌ها و شبکه‌های اجتماعی به اشتراک بگذارید.

مهم: فایل ZIP را به‌تنهایی داخل مخزن قرار ندهید؛ محتویات آن باید استخراج و بارگذاری شود.
دکمه دانلود به فایل Payesh-v15.1.apk در ریشه همین سایت وصل است.
بدون دسترسی به حساب کاربری یا هاست شما، از اینجا امکان دادن نشانی فعال عمومی نداریم.
انتشار در GitHub Pages عمومی است؛ فایل APK برای همه افراد قابل دریافت خواهد بود.

تأییدهای انجام‌شده:
- تمام فایل‌های APK اولیه بدون تغییر کپی شده‌اند.
- فایل ZIP/APK از نظر خوانده‌شدن و CRC بررسی شده است.
- اجرای واقعی نرم‌افزار روی گوشی یا دسترسی‌پذیری سایت از همه شبکه‌ها در اینجا آزموده نشده است.
